# React MUI UI Tasks

A React application built using Material UI (MUI) that combines three UI tasks in a single project.

## Features

- **User Management:** Display and filter users by age.
- **MUI Contact Card:** A contact card designed using Material UI components.
- **Cricket Event Form:** A form for creating cricket events.
- **Home Page:** Navigate between the three tasks using clickable cards.
- **React Router:** Navigate between pages without reloading the application.

## Technologies Used

- React
- JavaScript
- Material UI (MUI)
- React Router DOM
- CSS

## Getting Started

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL displayed in the terminal.

## Project Purpose

This project demonstrates reusable React components, Material UI styling, form handling, filtering, and client-side routing.
